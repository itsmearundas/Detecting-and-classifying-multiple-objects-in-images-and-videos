Want to run this for real?

Get the full source — real YOLOv8 + EfficientNet-B0 inference on your own images and videos, no sample data, no demo banner.

⬇ Download from GitHub

Run it end-to-end on your machine

1Clone the repo

git clone https://github.com/itsmearundas/Detecting-and-classifying-multiple-objects-in-images-and-videos.git
cd Detecting-and-classifying-multiple-objects-in-images-and-videos/hybrid

2Install dependencies (Python 3.10+ recommended)

pip install -r requirements.txt

3Run the app locally

python app.py
# → open http://localhost:5000

4(Optional) Run it in Docker instead

docker build -t hybrid-vision .
docker run -p 7860:7860 -e PORT=7860 hybrid-vision
# → open http://localhost:7860

5Want it hosted online instead of local? See DEPLOY.md in the repo — it needs roughly 2GB RAM to hold both models in memory, so most free serverless tiers won't fit it. A small VPS or a paid Render "Standard" instance both work well.
